# API 수동 확인 도구

이 디렉터리의 스크립트는 자동화 테스트가 아니라 외부 API 응답과 좌표 경계를 개발자가
수동으로 점검할 때 쓰는 진단 도구입니다. Vitest 및 CI 테스트 수에는 포함되지 않습니다.

프로젝트 루트에서 다음처럼 실행합니다.

```bash
node scripts/probe/<파일명>.js
```

외부 API를 호출하는 스크립트는 루트의 `.env` 또는 `.env.local`에 해당 키가 있어야
합니다. 키가 없는 경우 실패 메시지만 확인하고 종료하는 것이 정상입니다. 실행 전 대상
API와 요청 범위를 확인하고, 출력에 키나 토큰을 추가하지 마세요.
